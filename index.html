一间茶寮

一壶慢慢泡开的乌龙

乌龙茶的地盘是一个 Java 版 26.2 的社区服务器。比起人声鼎沸的大服，我们更想留一块安静的地方：种田、搭房、研究红石，或者只是盖一座自己满意的小房子。

名字取自一壶乌龙茶——热乎、回甘、常来常新。服主把这里当自家地盘打理，进来的每一位玩家，也都当这里是半个家。规矩不多，但互相尊重是底线。

想怎么玩，都给你留了位置

不用按照别人的玩法生活。挑一种喜欢的姿势入座，剩下的交给时间。

生存定居

圈一块地，种一片田，把「家」从几根木头慢慢盖成一座村子。日出而作，日落而息。

红石工坊

给爱折腾电路的玩家留的桌位：自动农场、电梯、刷物机。折腾本身就是乐趣，坏了重来也不亏。

建筑茶楼

中式、欧式、像素画，来者不拒。好作品会挂进「纪念馆」，让路过的人都能看上一眼。

社区茶会

不定期小活动、主题周和集体项目。人多热闹，人少清静，怎么都舒服，来了就是茶友。

茶余问答

进门前，先听几嘴家常

服务器是 Java 版还是基岩版？＋
Java 版，目前支持版本 26.2。具体兼容的版本范围以群内公告为准，升级前后都会提前通知。
怎么获取服务器地址？＋
地址不公开，安装客户端整合包后多人游戏内置服务器链接。也顺便认识一下群友，进服不孤单。
服务器有什么规则？＋
进服先看公告。核心就几条：不偷、不抢、不破坏；友善交流；细节以公告为准。
可以和朋友一起建东西吗？＋
当然。合作建筑是这里最受欢迎的活动之一，大型项目也可以向服主申请专属区域，一起把地盘越建越大。
服务器会经常维护或清档吗？＋
常规维护会提前在群里通知，尽量选在凌晨进行。建筑和物资都会尽力保留，具体以公告为准。
