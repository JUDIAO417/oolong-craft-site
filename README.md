# 乌龙茶的地盘 · Oolong Craft

「在方块与茶香之间，建一个家」——Java 版 26.2 慢节奏社区服务器的官网。

## 站点信息

- 平台：Java 版 Minecraft
- 支持版本：26.2
- 服务器地址：不公开，通过玩家群 / 私聊服主获取

## 技术栈

- 单文件 HTML（内联 CSS / 原生 JS），无构建依赖
- 配图位于 `assets/`，均由 AI 生成（Minecraft 方块风格）
- 字体走自托管镜像（miaoda.feishu.cn）

## 本地预览

直接双击 `index.html` 即可在浏览器中打开。

## 修改提示

- 想改文案：直接编辑 `index.html` 中对应文字
- 想换配图：替换 `assets/` 下同名图片（保持比例即可）
- 想加群链接：在「加入我们」/ 页脚区域插入群邀请链接
